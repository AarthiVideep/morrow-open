# morrow: Open a Sealed File

This page opens a morrow Sealed File in a web browser. Use it on an iPhone, where a file preview cannot open the file, or on any
device where the file does not open by itself.

Open the page: https://aarthivideep.github.io/morrow-open/

## How to use it

1. Save the Sealed File you were given. On an iPhone, open it in WhatsApp or Mail, tap Share, then Save to Files.
2. Open the page above, and choose the Sealed File.
3. Enter the passphrase from the paper you were given.

The file opens here, in your browser, and is not uploaded.

## About this copy

The main address is https://open.dearmorrow.co. This copy is the same page, kept here so that a Sealed File can still be
opened if that address cannot be reached.
